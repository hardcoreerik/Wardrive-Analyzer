# Contributing

Wardrive Analyzer is a solo development project. I'm not accepting pull
requests or code contributions at this time.

**Pull requests will be closed without merging.**

## Bug Reports

Bug reports are welcome. Open an Issue with:

- What you were doing when the problem occurred
- What you expected to happen
- What actually happened
- OS, Python version, and any relevant error output

## Forks

You're welcome to fork this project and build on it for your own use.

## Why solo?

This is a personal analysis tool I develop and test against my own data and
workflow. Keeping it solo lets me move fast and ship without a review process.

For security-related reports, see [SECURITY.md](SECURITY.md).
